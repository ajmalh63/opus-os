# Study Abroad — Counsellor Walkthrough (Training Guide)

**Version:** 2026-08-15 · Applies to the current Study Abroad desk (agent + student portal).

---

## STEP 0 — A lead arrives (any channel)

| Channel | What happens automatically |
|---|---|
| Website lead form | Client record + token (`OP-2026-XXXX`) + engagement + DPDP consents + intent scoring + **15-min SLA task** to the least-loaded counsellor. Quick profile (CGPA/English/budget) → completeness starts ~50% |
| Walk-in | **+ Add Student** → name, email, phone, qualification, nationality (free-text) |
| WhatsApp / phone | Same as walk-in; log the call on the comms timeline |

**First action:** task board → SLA task → **call/WhatsApp within 15 minutes**.

## STEP 1 — Open the student (Student Profiles tab)

- **Registry**: search by name/ID; cards show GPA, country, **completeness % bar**, **📝 notes indicator**
- **Overview**: summary strip (Applications · In Progress · Offers · Next Deadline) · **💬 Communication Log** (channel chips, Enter to save) · **📝 Internal Notes** (staff-only) · Academic Profile (CGPA, English test/score) · Target Preferences (country 50+ / intake / budget / app ref / portal email / CAS) · **Edit Profile ✎** · **📝 Intake Wizard** · **📄 CSV export**

## STEP 2 — Intake wizard (4 steps)

1. **Academic** — CGPA, 10th/12th %, degree, graduation year, backlogs, gap years, work experience
2. **Tests** — English test (IELTS/TOEFL/PTE/Duolingo/Cambridge) + score or **planned** + date, GRE, GMAT, **English-medium waiver**
3. **Preferences** — country (free-text), intake, course, budget, scholarship need
4. **Review & Consent** — passport, parent contact, **DPDP university-sharing consent** → summary

Save → 100% → staff alert + student email.

## STEP 3 — New Application modal (snapshot)

University (name/country/city/website/portal URL+username — **no passwords**) · Program (title/degree/intake/deadline) · Requirements (min CGPA, English test+min score, GRE, tuition range) · Fees (application fee, scholarships) · Notes.
**Live Match/Reach/Safe badge** updates as you type. Create 4–6 (2 ambitious / 2 match / 2 safe).

## STEP 4 — Applications tab (per-student)

🎯 Pipeline strip (8 columns) · cards with match badge, deadline chip, match reasons, **doc checklist chips** (missing→received→verified), **offer panel** (accept/decline), rejection banner, **status dropdown (legal moves only)**, record-offer-details.

## STEP 5 — Kanban Pipeline tab (cockpit)

Pipeline Health (total/stuck/decisions/deadlines) · filters (country/intake/tier) · 8 columns + Rejected · rich cards · status dropdowns · View ➔ deep-link.

## STEP 6 — Documents (two-way sync)

Student upload → checklist **received** + alert + task → you **Approve/Reject** → student sees instantly + email.

## STEP 7 — Offers & enrollment

Offer Letter → email + acceptance task → record details → student accepts/declines → deposit task → visa prep → Enrolled.

## Daily routine (10 min)

1. Pipeline Health → act on stuck/decisions/deadlines
2. Task board → auto-tasks
3. Registry → amber completeness → chase / intake wizard
4. Documents → verify uploads
5. Comms log → log every call
